# Campus Event Management System (Backend)

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Refresh Tokens
- Spring Data JPA
- MySQL
- Java Mail
- Pagination
- Global Exception Handling

## Features

- Role Based Authentication
- Student
- Club
- Admin
- Event Creation
- Event Approval
- Registration Approval
- Forgot Password
- Email Notifications
- JWT Refresh Tokens
